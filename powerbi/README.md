# Power BI Dashboard

This folder contains the Power BI report for the Nursing Home Quality & Performance Dashboard.

## File Included
- `nursing_home_dashboard.pbix` – Power BI report file

## Dashboard Pages
- Overview Page
- Quality Page  
- Staffing Page 
- Facility Page 

## Features
- Clean data model using cleaned Excel dataset
- DAX measures for ratings, counts, and averages
- Navigation sidebar for multi‑page experience
- Consistent color theme and layout
